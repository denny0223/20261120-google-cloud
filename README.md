## 示範

- 在終端機用鍵盤選取檔案路徑，再把路徑帶入指令。[Kitty Hints 操作示範](https://github.com/denny0223/kitty-showcase/blob/master/guides/zh-TW/3.txt)
- 在 Neovim 開啟同一份 Markdown，查看圖片與 Mermaid 流程圖。[示範筆記](assets/demo/kitty-notes.md) · [md-render.nvim](https://github.com/denny0223/md-render.nvim) · [上游專案](https://github.com/delphinus/md-render.nvim)
- 在 Antigravity 的 Swarm board 查看誰正在工作、哪個變更在等審查。[完整看板截圖](assets/demo/antigravity-board.png)
